# 术语与纠错表示例
#
# 用法：复制本文件为同目录下的 glossary.txt，再按自己的场景改写。
#   cp references/glossary.example.txt references/glossary.txt
# glossary.txt 已在 .gitignore 里，不会被提交。
#
# 格式：一行一条， 错误写法 => 正确写法
# 「#」开头为注释，空行忽略；左侧长的规则自动优先，不用手工排序。
# 只做确定性字符串替换：命中才改，没命中逐字不动，不影响时间戳与断句。
#
# 两条原则：
# 1. 左侧必须带上下文。写 `爆款股价 => 爆款骨架` 而不是 `股价 => 骨架`，
#    否则讲到真实股价时会改错。
# 2. 只放"确定的错"。不确定的宁可留给人工核对，也不要写进来。


# ── 专有名词：大小写与拼写变体 ──
# 语音识别的输出大小写很不稳定，这类可以放心收敛。
Chat GPT => ChatGPT
chatgpt => ChatGPT
Github => GitHub
github => GitHub
javascript => JavaScript
typescript => TypeScript

# ── 中文同音字、错别字 ──
# 左侧尽量带 1–2 个字的上下文，避免误伤同音但正确的词。
以经 => 已经
在次 => 再次
即然 => 既然
做为一个 => 作为一个
按装 => 安装

# ── 自己加 ──
# 新视频/录音里出现的专有名词，第一次听错后补一行，下次同类内容直接免疫。
# 例如：
# Midjourny => Midjourney
# Kubenetes => Kubernetes
